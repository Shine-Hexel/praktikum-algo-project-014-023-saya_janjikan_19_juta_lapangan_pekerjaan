# praktikum-algo-project-014-023-saya_janjikan_19_juta_lapangan_pekerjaan
Project Akhir Praktikum Algoritma & Struktur Data Kelompok 5 SI-A
Arsi Candra Kusuma (124250023) & Annisa Rahma Pratita (124250014)

Program ini merupakan sistem sederhana berbasis C++ untuk mengelola daftar tugas (to-do list) menggunakan struktur data linked list ganda (double linked list).  
Fitur utama meliputi penambahan, penghapusan, pencarian, penyimpanan ke file, serta pengelolaan status tugas (In Progress, Late, Done).

Aplikasi ini dibuat sebagai Tugas Akhir Praktikum Algoritma & Struktur Data dengan menerapkan materi sebagai berikut:
- Struktur data linked list
- File pointer handlig
- Sorting dan searching
- CRUD
